# 녹화본은 서버를 거쳐 저장·재생하고, 저장 총량을 서버가 제한한다

녹화본은 OCI Object Storage(비공개 버킷, S3 호환 API)에 두되, 업로드와 재생 모두 서버를 거친다(재생은 Range 요청 프록시). 서명 URL로 브라우저가 직접 올리고 받는 방식은 서버 부하가 적지만, 쿼터 검사를 사후로 미뤄야 하고 버킷 CORS·고아 객체 정리가 필요하다. 계정이 PAYG라 Always Free 한도(Object Storage 20GB)를 넘으면 즉시 과금되므로, 서버가 업로드 시점에 녹화본 총량(`STORAGE_QUOTA_BYTES`, 기본 15GB)을 강제할 수 있어야 했다. 같은 이유로 비밀 값 없이도 돌아가는 `STORAGE_BACKEND=local`을 기본값으로 둔다.

## Consequences

- 재생 트래픽이 VM을 통과한다. 아웃바운드 무료 한도(월 10TB) 안에서는 문제없다.
- DB에는 녹화본의 저장소 종류와 객체 키, 크기를 함께 기록한다.
